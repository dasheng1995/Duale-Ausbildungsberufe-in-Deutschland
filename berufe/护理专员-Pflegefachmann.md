# 护理专员（Pflegefachmann / Pflegefachfrau）

> 调查基准：本职业不属 BBiG/HwO 经典双元制 DAZUBI 口径；规模取 Destatis 护理培训统计 2024；津贴取公共部门 TVAöD Pflege（约 2025-04）。
> 金额均为**月薪**；税后为单身、税级 I（Steuerklasse I）、无教会税、法定医保的近似估算，实际到手因联邦州、医保附加费率、有无子女而略有差异。
> 文中人数若写作德语千分位写法（如 `59.400`），不是小数。
> 中文便于阅读；申请、合同、考试请以括号内**德语官方名称**为准。
> **重要**：本页属卫生健康类学校教育职业（Gesundheitsfachberuf），法律路径与资料库主体「BBiG/HwO 双元制」不同，但同样可**自行向实践培训承担方申请**、签合同、拿**培训津贴（Ausbildungsvergütung）**，日常形态高度相似。
> 第 1–9 节偏职业画像；找机构与生活账见第 10–12 节；第 13–14 节为核验与口径说明。

## 一句话结论

护理专员是国家承认的卫生健康类培训职业，官方名称 **Pflegefachmann / Pflegefachfrau**，学制 **36 个月**（约 3 年），资格框架约 **DQR 4**。2024 年新签培训合同约 **59.400**，年末在训约 **146.700**，当年成功结业约 **37.400**。年轻人常因**轮班夜班、情感劳动重、责任大与身体负荷**犹豫。津贴与结业薪资见第 4–5 节。**可自行申请**：向医院/护理机构/急救服务等实践培训承担方（Träger der praktischen Ausbildung）投递，签培训合同并领取津贴。

## 1. 职业是什么、学什么

| 项目 | 内容 |
| --- | --- |
| 官方名称 | Pflegefachmann / Pflegefachfrau |
| 法律依据 | 《护理职业法》（Pflegeberufegesetz，PflBG）；配套《护理职业培训与考试条例》（PflAPrV） |
| 主管范围 | 卫生健康类学校教育（Gesundheitsfachberuf），**不是** BBiG/HwO 经典双元制 |
| 学制 | 通常 **36 个月**；部分可部分时间制延长 |
| 资格等级 | 约 DQR **4**（以结业证书与州规定为准） |
| 学习形式 | 护理学校（Pflegeschule）理论课 + 实践培训承担方（医院/养老/居家护理）及轮转实习；理论约 2.100 学时、实践约 2.500 学时 |
| 职业主组 | Gesundheits- und Pflegeberufe（卫生护理） |

### 工作现实（签约前要想清楚）

- **场景**：医院病房、养老院、居家护理等，护理各年龄段患者
- **典型任务**：基础与专科护理、用药与观察、文档交接、患者与家属沟通、急救配合
- **体力 / 班次 / 客户压力**：常有轮班、夜班、节假日；情感劳动与责任重。结合第 8 节与试工/实习判断。
- **德语**：患者沟通、交接班、文件与安全指令，实务上多需 **B2**（部分机构硬性要求）。
- **学历**：常见为中等学历（约 10 年普通教育）或主体中学 + 至少两年职业培训/护理辅助前置；以招聘与学校招生条件为准。
- **健康与无犯罪证明**：通常需健康适宜证明（gesundheitliche Eignung）与无犯罪证明（Führungszeugnis）。

### 职业学校 / 护理学校上什么课（主题粗览）

| 序号 | 主题（中文） | 德语关键词 |
| --- | --- | --- |
| 1 | 护理过程与沟通 | Pflegeprozess und Kommunikation |
| 2 | 解剖生理与疾病学基础 | Anatomie, Physiologie, Krankheitslehre |
| 3 | 药物与安全 | Pharmakologie und Patientensicherheit |
| 4 | 急危重症与急救基础 | Notfall und Intensivgrundlagen |
| 5 | 儿科/老年/精神科轮转主题 | Pädiatrie, Geriatrie, Psychiatrie |
| 6 | 法律、伦理与专业身份 | Recht, Ethik, Berufsrolle |

## 2. 岗位规模、培训规模、通过率

### 培训规模

| 指标 | 数字 | 说明 |
| --- | --- | --- |
| 在训 / 库存 | **约 146.700 人** | Destatis 2024，各年级叠加 |
| 当年新签 / 入学 | **约 59.400 份** | 较 2023 约 +9% |
| 当年结业通过 | **约 37.400 人** | 通用护理结业占绝大多数 |
| 性别结构粗感 | **女性约七成以上** | 行业常见结构；急救岗男性占比通常更高 |

### 中途退出与考试

官方公开「解除率/考试成功率」口径与 BBiG 不同；实务上前两年因班次与压力退出并不少见，签约前务必实习。

### 就业侧

结业后进入医院、养老、居家护理；行业持续缺人，但夜班与责任仍是留人关键。

## 3. 申请竞争难度（非 BBiG ANR 口径）

**总评：整体机会多，但好医院/大城市仍挑德语、实习与抗压表现**

本职业**没有** BIBB Tabelle 59 那种 ANR 供需比。竞争看：**实践培训承担方是否招满、德语与健康门槛、是否完成规定实习（Praktikum）**。

| 读数要点 | 含义 |
| --- | --- |
| 行业缺人报道多 | 不等于「人人好进」；大医院/大城市仍挑人 |
| 实习与试工 | 手术室/护理/急救常要求事前实习，卡住一批申请人 |
| 德语 B2 | 外籍申请人实务硬门槛 |
| 班次接受度 | 书面愿意上夜班 ≠ 试工后仍愿意 |

## 4. 培训期间到手工资（Ausbildungsvergütung）

合同写的是**税前（brutto）**。下表以公共部门学徒劳资 **TVAöD Pflege**（约自 2025-04-01）为全国可核对的公开锚点；教会/私立集团可能接近或略有出入，**以书面合同为准**。

### 公共部门参考税前（TVAöD Pflege，约 2025-04）

| 年级 | 税前月均（约） |
| --- | --- |
| 第 1 年 | **1416 €** |
| 第 2 年 | **1477 €** |
| 第 3 年 | **1578 €** |

### 税后到手（近似，税级 I）

| 税前 | 约到手（netto） | 适用场景 |
| --- | --- | --- |
| 1416 € | **约 1119 €** | 一年级参考 |
| 1477 € | **约 1167 €** | 二年级参考 |
| 1578 € | **约 1247 €** | 三年级参考 |

另可能有：年终奖（Jahressonderzahlung）、结业奖金、交通/值班补贴——是否发放看劳资与机构，上表未计入。

## 5. 毕业后税前 / 税后工资

> 下列为**市场区间估算**（公共部门 TVöD/私立集团常见水平），用于建立数量级；同一职业东西部、班次、科室与劳资可差数百欧元。

| 口径 | 税前月薪 | 约税后（税级 I） |
| --- | --- | --- |
| 入门 / 偏低 | 约 **2800 €** | 约 **1904 €** |
| 常见中位附近 | 约 **3400 €** | 约 **2176 €** |
| 偏高 / 有经验 | 约 **4200 €** | 约 **2688 €** |
| 升阶后（专科/管理/教学） | 约 **4.500–5.800 €** | 随岗位波动 |

**年薪粗算**：税前月薪 × 12；若有双薪/假期奖金，再加 0,5–1,5 个月。

## 6. 职业发展路线（能做什么、考什么、多少年）

### 时间线示意

| 阶段 | 大约时间 | 身份 / 证书 | 典型岗位 | 收入量级（税前/月） |
| --- | --- | --- | --- | --- |
| 0 | 培训期 | 在训生 / 卫生学校学员 | 跟班实践 | 见第 4 节 |
| 1 | 结业当年 | 国家承认结业 | 病房/居家护理专员 | 约 2800–3400 € |
| 2 | 结业后 1–3 年 | 有经验专员 | 责任护士/专科方向 | 约 3400–4200 € |
| 3 | 结业后 2–5 年+ | 专科/教学/协调 | 护理管理或教学 | 约 4.500–5.800 € |
| 4 | 再往后 | 管理、高校路径、对口进修 | 部门协调或深造 | 波动大 |

### 关键证书说明

1. **国家结业考试**：通过后获职业执业资格相关结业（以本职业法律与州考试机构为准）。
2. **专科进修（Fachweiterbildung）**：重症、手术、急救、儿科、精神科等（视职业开放路径）。
3. **旁路**：部分可衔接护理/健康相关高校学士（含部分实践整合路径）。

## 7. 值不值得读（综合判断）

| 维度 | 判断 |
| --- | --- |
| 好不好进 | 相对好找 Träger；硬门槛在德语、健康与实习 |
| 好不好毕业 | 能坚持轮转与考试者多数能过；真正难的是班次适应 |
| 培训期钱 | 一年级税前常见约 **1416 €** 量级（公共部门锚点；以合同为准） |
| 毕业钱 | 税前常见约 **2800–4200 €** 带 |
| 天花板 | 专科进修与管理岗可再高一截；不适合指望轻松坐班 |
| 适合谁 | 愿意轮班、能做身体护理与情绪劳动、想尽快就业 |
| 不太适合谁 | 只想白天坐班、怕血/排泄物/冲突场景、德语听力不够的人 |

## 8. 为什么德国年轻人仍犹豫（纸面不错，却招不满）

> 本节对齐行业缺人报道与学员/家长常见顾虑：轮班夜班、情感劳动重、责任大与身体负荷。

听起来不错，通常是因为看到了**结果面**：有合同、有津贴、行业喊缺人、结业能就业。年轻人卡住的是**班次、身体与情感负荷、同学比较**。

### 为什么「纸面不错」，年轻人仍犹豫

**1. 班次与责任**  
轮班夜班、情感劳动重、责任大与身体负荷——比「有没有饭碗」更影响志愿。

**2. 家长期望与升学惯性**  
部分家庭更推大学或「干净」办公岗；护理/急救/手术室形象常被低估。

**3. 钱与体感**  
培训期一年级约 **1416 €** 税前已属卫生类偏高档；但结业后责任与班次对上工资后，仍常觉得「不值」。

**4. 信息不对称**  
好机构靠实习才看得见；招人季与学生定方向时间错开。

## 10. 怎么找机构与申请时间线

### 去哪找（无外链，记渠道名）

- 医院、养老院、居家护理服务的「Ausbildung Pflegefachmann/-frau」招聘
- 联邦就业局培训/就业市场栏；关键词用官方德语名
- 护理学校招生页（有的代招，合同仍与 Träger 签）
- 教会与公益集团（Caritas、Diakonie 等）培训广告

简历与邮件用德语；写明可到岗时间、德语级别、已完成/可安排的实习、是否接受轮班。

### 建议时间线（常见春/秋开学）

| 时间 | 做什么 |
| --- | --- |
| 开学前 **9–12 个月** | 德语冲到 B2；确定联邦州；联系 Träger + 学校 |
| 开学前 **6–9 个月** | 完成规定实习；试工；锁定意向机构 |
| 开学前 **3–6 个月** | 签合同、确认津贴与学校名额；准备健康证明与无犯罪证明 |
| 开学前 **1–3 个月** | 签证/租房缓冲（如适用）；确认排班与报道 |

### 实习怎么用

目标是双方确认你能否接受真实班次与场景。口头「可以」必须落到**书面培训合同**与津贴数字（对照第 4 节）。

## 11. 培训日常节奏与考试节点

| 模块 | 典型情况 |
| --- | --- |
| 理论课 | 卫生学校 / 护理学校，常为集中授课块（Block） |
| 实践 | 在 Träger 及轮转机构；实践课时通常多于理论 |
| 工时与假期 | 青少年与成年规则不同；夜班/周末常见，看合同与劳资 |

### 考试节点

1. **中期/过程考核**：培训中段有中间考试或过程评估。  
2. **国家结业考试**：笔试、口试与实践考试；通过后获 Pflegefachmann/-frau 结业。

## 12. 培训期生活账（到手够不够花）

第 4 节到手是**收入起点**。一年级约 1119 € 税后在小镇/合租更易打平；大城市仍可能紧张。

| 项目 | 较低成本地区 / 合租 | 高成本大城市 |
| --- | --- | --- |
| 房租+杂费 | 约 350–550 € | 约 550–900 €+ |
| 交通 | 约 50–100 € | 同左或更高 |
| 饮食+手机+日用 | 约 200–350 € | 约 250–400 € |
| **合计粗感** | 约 **650–1.000 €** | 约 **900–1.400 €+** |

外籍建议在签合同前问清工作地邮编、是否协助找房，并自备数月缓冲金。

## 13. 一手交叉核验清单（防只看纸面）

1. 用官方德语名 `Pflegefachmann` 在就业局与 Ausbildung/医院招聘栏抽样近 20 条要求。
2. 完成该职业要求的实习天数，记录夜班/气味/压力是否可长期接受。
3. 合同对照第 4 节 TVAöD 锚点；长期含糊「以后再谈津贴」的慎重。
4. 确认合作学校名称、开课日期、是否已预留名额。
5. 核对德语证明、健康证明、无犯罪证明有效期。
6. 用工作地址查房租，拿预计 netto 估三个月现金流。
7. 若跨境赴德：提前核对签证类别是否覆盖此类卫生培训合同。
8. 对照第 8 节：若你卡在班次/情感劳动/血腥场景——解除或退学风险会落到你身上。
9. 问清结业后目标科室是否与培训轮转一致。
10. 数字口径：规模多取 Destatis/行业报道；津贴取 TVAöD 公开表；毕业薪资为区间估算。

## 14. 信息来源与口径说明（无外链版）

- 法律与学制：各职业联邦法律（如 Pflegeberufegesetz、Notfallsanitätergesetz、ATA-OTA-G）及配套考试条例。
- 护理规模：联邦统计局（Destatis）护理培训统计（如 2024 新签约约 59.400、在训约 146.700、结业约 37.400）。
- 培训津贴：公共部门 TVAöD Pflege 学徒表（约 2025-04 起：一年级约 1.416 €、二年级约 1.477 €、三年级约 1.578 €）。
- 结业后市场薪资：就业市场常见区间与公共/私立医院招聘粗感（非个人报价）。
- 申请流程：向 Träger der praktischen Ausbildung 自申 + 合作卫生学校上课，为行业通行做法。

本页**刻意标注**其不属于 BBiG 经典双元制，以免与资料库其余职业混口径。阅读时勿把 ANR/DAZUBI 指标直接套用到本职业。
